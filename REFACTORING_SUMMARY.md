## How to Update the Version

To release a new version, edit **only** the `VERSION` variable in `build.sh`:

```bash
VERSION="0.0.2"  # Change this number
```

Then run the build and push to GitHub:

```bash
./build.sh
git add info.plist VLX.alfredworkflow build.sh
git commit -m "Bump version to 0.0.2"
git push origin main  # For production release
# or
git push origin beta   # For beta release
```

GitHub Actions will automatically:
1. Build the workflow
2. Create a release with the version from the plist
3. Attach the `.alfredworkflow` file
